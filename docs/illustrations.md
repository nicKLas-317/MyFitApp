# Illustrations des exercices : sources et licence

Conformément au §4.0.1, les illustrations sont embarquées dans l'application et fonctionnent hors ligne.

## Ce qui est utilisé

Des **pictogrammes SVG originaux**, dessinés pour MyFitApp (`src/ui/Pictogram.tsx`), sans aucune ressource externe :

- un pictogramme par type de matériel : machine (pile de charges), poulie (roue, câble et poignée), haltères, barre, poids du corps, autre ;
- un fond teinté selon le groupe musculaire principal (dos, pectoraux, épaules, biceps, triceps, jambes, abdominaux). Les teintes sont choisies loin du vert, de l'orange et du rouge réservés aux statuts de progression (§8).

Ces pictogrammes font partie du code source du projet et suivent sa licence.

## Pourquoi pas de photos ou de dessins d'exercices

Aucune banque d'illustrations d'exercices de musculation n'a pu être retenue avec une licence de réutilisation vérifiable (domaine public, CC0 ou licence libre compatible) pour chaque image. Faute de garantie, aucune image n'a été téléchargée, comme le demande le brief. Les pictogrammes distinguent le matériel et le groupe musculaire ; le nom, la variante et les synonymes complètent l'identification.

Si des illustrations sous licence vérifiée sont ajoutées plus tard, indiquer ici pour chacune : la source, l'auteur, la licence et le lien vers le texte de la licence.
